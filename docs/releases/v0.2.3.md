# NEUOJ 小助手 0.2.3

本次发布将 Beta 阶段的功能整理为正式版，浏览器扩展和 CLion 插件统一使用版本号 0.2.3。

## 新增 CLion 插件支持

在 NEUOJ 题目页点击“导入题目”，即可把题面和样例关联到 CLion 当前选中的本地 C/C++ 文件。在 IDE 中可运行单个或全部样例，切换忽略空白与逐字符比较，编辑 TC1 或添加自定义样例，并查看程序的 CPU 用时、退出码和编译诊断。

插件支持自动探测或手动配置编译器，可选择 C/C++ 标准、`-O2` 优化和自定义编译参数。提交代码时，插件通过浏览器扩展使用现有的 NEUOJ 登录态；用户确认后才发送源码。导入、本地测试和提交均无需配置模型 API。

本地测试不实施线上内存限制，结果不等同于线上评测。线上提交语言为 C 或 C++14，提交成功仅表示站点接受请求。

## 安装与升级

从[本次 Release](https://github.com/StoneXieAC/neuoj-helper/releases/tag/v0.2.3) 下载对应组件：

| 组件 | 支持版本或平台 | 附件 |
| --- | --- | --- |
| Chrome / Edge 扩展 | 110 或更新版本 | `neuoj-helper-0.2.3-chrome.zip` |
| Firefox 扩展 | 115 或更新版本 | `neuoj-helper-0.2.3-firefox.xpi` |
| CLion 插件 | macOS arm64 / x86-64 | `neuoj-clion-helper-0.2.3-macos.zip` |
| CLion 插件 | Linux x86-64 | `neuoj-clion-helper-0.2.3-linux-x64.zip` |
| CLion 插件 | Windows x86-64 | `neuoj-clion-helper-0.2.3-windows-x64.zip` |

CLion 支持 2023.3–2026.2，兼容性检查覆盖 2023.3、2024.2、2025.2 和 2026.2.2。Firefox 附件已通过 Mozilla 签名。浏览器扩展同时支持校园网直连和东北大学 WebVPN。

请同时更新浏览器扩展和 CLion 插件，更新后刷新 NEUOJ 题目页并重新点击“导入题目”，建立本次会话的配对。重启 CLion 后也需重新导入。

安装和使用步骤见 [README](https://github.com/StoneXieAC/neuoj-helper/blob/v0.2.3/README.md) 与 [CLion 插件指南](https://github.com/StoneXieAC/neuoj-helper/blob/v0.2.3/clion-plugin/README.md)。原有的提交错误分析功能仍可独立使用。
