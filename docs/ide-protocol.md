# IDE 本地协议 v1

该协议与 IDE 类型无关。浏览器扩展负责读取 NEUOJ 页面，接收端负责管理本地题目；首版接收端为 CLion 插件。

## 本机连接

插件只监听 `127.0.0.1:27121`。导入目标是最近使用的 CLion 窗口里当前选中的本地代码文件；没有可用文件时返回错误。扩展仅声明 `http://127.0.0.1/*` 的固定本机访问权限。浏览器后台仅在用户点击导入后发送题目；正式提交仅在用户点击 CLion 按钮并确认后发送源码。站点 Cookie 不经过本机协议。

插件校验 `Host: 127.0.0.1:27121`；有 `Origin` 时只接受浏览器扩展来源，不提供网页跨域授权。端口固定且不自动更换。导入时扩展生成本次浏览器会话的随机配对值，通过 `X-NEUOJ-Pair` 请求头交给插件。读取待提交源码及回报结果须带同一配对值；插件重启或扩展会话结束后需重新导入题目。本机接口不提供任意路径写入或命令执行。

## 接口

`GET /v1/capabilities` 返回：

```json
{"protocolVersion":1,"capabilities":["importProblem","submitCode"],"ide":"CLion"}
```

`POST /v1/problems` 使用 `application/json` 和 `X-NEUOJ-Pair`，正文最大 2 MiB：

```json
{
  "protocolVersion": 1,
  "id": "https://oj.neu.edu.cn/problems/83",
  "url": "https://oj.neu.edu.cn/problems/83",
  "title": "示例题目",
  "statement": "纯文本题面",
  "images": [],
  "timeLimitMs": 1000,
  "memoryLimitMb": 512,
  "samples": [{"id":"official-1","input":"1\n","output":"1\n"}]
}
```

资源限制无法识别时为 `null`。样例字符串不截断、不整理空白；允许空输入或空输出，但样例数组必须非空，最多 100 组，编号唯一。题面以文本展示，图片仅保留地址。

普通访问的 `id` 是无查询参数、片段及尾斜杠的题目地址。代理访问使用 `webvpn:<NEUOJ路径>`；`url` 保留查询参数，清除片段。两种入口分别存储，代理地址仅接受项目既有固定前缀。

支持路径：`/problems/<题号>`、`/training/<ID>/part/<ID>/problem/<题号>`、`/group/<ID>/problem[s]/<题号>`、`/contest/<ID>/problem/<题号>`、`/exam/<ID>/problem/<题号>`。题号为字母数字，范围 ID 为数字。

成功返回 `{"ok":true,"id":"..."}`，表示题目与样例已在本次 CLion 会话中关联到当前代码文件；导入不会创建或打开代码文件。

| 状态码 | 含义 |
| --- | --- |
| 200 | 请求成功 |
| 400 | 数据无效、超过限制或工作区无法写入 |
| 403 | 浏览器来源不符合要求 |
| 404 | 接口或方法不支持 |
| 409 | 未找到最近使用的 CLion 窗口或其中没有可用的本地代码文件 |

浏览器先查询能力，再导入题目，总超时 10 秒；不自动重试。重复导入不会修改源码，自定义样例在本次会话中保留，官方样例按新题目数据更新。

## 正式提交

CLion 仅对当前选中且与题目关联的文件启用提交。用户点击并确认后，插件保存编辑器内容并建立一次性任务。每个任务的 UTF-8 源码最多 1 MiB，语言为 `C` 或 `C++14`；本地 C/C++ 标准映射到这两个线上选项。浏览器保持至少一个已登录的同入口 NEUOJ 标签页，无需切回网页。

- 扩展后台携配对请求头长轮询 `GET /v1/submissions/next`，无任务返回 204；有任务返回 `{"id":"UUID","problemId":"...","url":"...","language":"C++14","source":"..."}`。每个任务只交付一次，不自动重投。
- 扩展在与题目同源、同代理前缀的页面使用 NEUOJ 的提交表单及登录态。随后以 `POST /v1/submissions/results` 回报 `{"id":"UUID","ok":true,"url":"提交详情地址"}`；失败时回报 `ok:false` 与 `error`。成功链接必须是同入口的 NEUOJ 提交详情地址。
- 插件最多等待 90 秒。连接中断、结果不明或站点未返回提交详情地址时，工具窗口顶部的原生提示栏显示“请在 NEUOJ 提交记录中核对提交结果。”，并提供同入口记录页的跳转链接。不会自动重试，以免重复提交。成功仅表示站点接受请求；协议不跟踪评测结果。

新增其他 IDE 可实现相同协议；源码只交给导入该题时配对的扩展会话。
