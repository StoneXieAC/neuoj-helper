# NEUOJ 小助手

为 [NEUOJ](https://oj.neu.edu.cn) 提供浏览器扩展和 CLion 插件，支持校园网直连与东北大学 WebVPN：

- 浏览器扩展读取错误提交的题面、源码和评测信息，调用你配置的模型接口分析原因。
- CLion 插件支持导入题面和样例、运行单文件 C/C++、比较输出及查看 CPU 用时，也可通过浏览器中的 NEUOJ 登录态提交代码。

错误分析需要配置模型 API；题目导入、本地样例测试和代码提交无需配置模型。

## 下载安装

从 [v0.2.3 正式版](https://github.com/StoneXieAC/neuoj-helper/releases/tag/v0.2.3) 下载：

| 组件 | 支持版本或平台 | 文件 |
| --- | --- | --- |
| Chrome / Edge 扩展 | 110 或更新版本 | `neuoj-helper-0.2.3-chrome.zip` |
| Firefox 扩展 | 115 或更新版本 | `neuoj-helper-0.2.3-firefox.xpi` |
| CLion 插件 | macOS arm64 / x86-64 | `neuoj-clion-helper-0.2.3-macos.zip` |
| CLion 插件 | Linux x86-64 | `neuoj-clion-helper-0.2.3-linux-x64.zip` |
| CLion 插件 | Windows x86-64 | `neuoj-clion-helper-0.2.3-windows-x64.zip` |

Chrome：解压 ZIP，打开 `chrome://extensions/`，启用开发者模式，选择“加载已解压的扩展程序”，选中解压后的目录。Edge 在 `edge://extensions/` 中启用开发人员模式，选择“加载解压缩的扩展”。

Firefox：打开 `about:addons`，在齿轮菜单选择“从文件安装附加组件”，选中 XPI 并确认数据传输权限。XPI 已通过 Mozilla 签名，重启后仍保留安装，无需关闭签名校验；更新时安装新版本的签名 XPI。

CLion：在设置的插件页选择“从磁盘安装插件”，安装对应系统的 ZIP 并重启。支持 CLion 2023.3–2026.2，兼容性检查覆盖 2023.3、2024.2、2025.2 和 2026.2.2。详细步骤见 [CLion 插件指南](clion-plugin/README.md)。

## 浏览器错误分析

1. 点击工具栏中的扩展图标，或提交页分析面板右侧的设置图标。
2. 打开“API 设置”，填写 API Base URL、API Key 和模型，点击“确认保存”。首次保存时，浏览器会请求接口域名权限。
3. 打开 NEUOJ 的提交详情页。评测完成并显示错误结果后，点击“分析错误”。

扩展从同源题目页读取题面，从提交页读取源码、编译错误和评测信息。题面无法获取或正文缺失时会提示重试，不发送分析请求；AC 提交不会发起分析。WA 分析保留页面提供的标准答案和用户输出，RE、TLE、MLE 等保留错误详情及有关退出状态。提示词总长上限为 24,000 字符，过长内容标记为 `[内容过长，已截断]`。

回答流式显示，支持 Markdown 和 LaTeX 公式。渲染脚本和字体随扩展提供；回答中的原始 HTML、图片和不安全链接不会执行或加载。若接口明确不支持流式请求，扩展会自动重试一次非流式请求。

最近 10 个提交的分析结果保存在本机。返回或刷新同一提交页时会恢复回答，点击“重新分析”可更新结果。缓存保存失败时仍显示当次回答，但刷新后可能无法恢复。面板右侧的复制图标可复制回答的 Markdown 原文，包括生成中的内容和缓存回答；没有回答时不可点击。

## CLion 题目与样例

安装浏览器扩展和 CLion 插件后，在 CLion 中打开本地 C/C++ 文件，再到 NEUOJ 题目页点击“导入题目”。题面和样例会关联到导入时选中的文件，导入不会新建源码文件或修改 CMake 配置。

在 NEUOJ 工具窗口中可运行全部样例或单个样例，切换忽略空白与逐字符比较，编辑 TC1 或添加自定义样例。插件支持自动探测和手动配置编译器，可选择 C/C++ 标准、`-O2` 优化和自定义编译参数。系统需已有可用编译器。

提交时保持浏览器及至少一个已登录的同入口 NEUOJ 标签页打开。在 CLion 选中关联文件，点击提交图标并确认。线上语言为 C 或 C++14；本地运行结果不等同于线上评测，提交成功仅表示站点接受请求。

升级时请同时更新浏览器扩展和 CLion 插件，刷新 NEUOJ 题目页并重新导入。重启 CLion 后也需重新导入。完整的运行限制和操作说明见 [插件指南](clion-plugin/README.md)，本机通信细节见 [IDE 协议](docs/ide-protocol.md)。

## 配置与数据说明

“测试连接”可在保存前检查接口信息。默认接口为 `https://api.deepseek.com`，默认模型为 `deepseek-flash`。Base URL 可包含 `/v1`，扩展会拼接 `/chat/completions`；支持 HTTPS 接口，以及 `localhost` 或 `127.0.0.1` 上的 HTTP 服务。

思考等级默认为 `low`。不支持该参数的接口可将其留空并保存，请求便不包含 `reasoning_effort`。“恢复修改”会将表单恢复到上次保存的内容，并保持窗口打开。“提示词设置”可编辑系统提示词，“恢复默认”会还原编辑框内容；修改后需点击“确认保存”。

API Key 只保存在浏览器的本机扩展存储中。题面、源码和评测信息仅在点击分析后发送给配置的模型接口。导入和提交通过本机连接传输所需数据，NEUOJ 登录 Cookie 不传给 CLion 插件。

Firefox 115–139 首次使用发送数据的功能前，需在设置中明确同意数据发送，也可随时撤回。Firefox 140 及之后使用浏览器内置授权。
