# NEUOJ 小助手

适用于 Chrome Manifest V3 的本地插件。它在 NEUOJ 提交详情页识别非 AC 结果，点击“分析错误”后读取对应题面、源码与有价值的评测证据，并调用用户配置的 OpenAI-compatible Chat Completions 接口。

## 安装与配置

1. 使用 Chrome 114 或更新版本，打开 `chrome://extensions/`，启用开发者模式，选择“加载已解压的扩展程序”，选中本仓库的 `extension/` 目录。
2. 点击工具栏中的插件图标或提交页分析面板角落的设置图标。在弹窗左侧选择“API 设置”或“提示词设置”，填写配置后点击“确定”；首次使用时会请求接口域名权限。
3. 打开直连或 WebVPN 的 NEUOJ 提交详情页。非 AC 且已评测完成时，点击页面上的“分析错误”。

默认接口为 `https://api.deepseek.com`，默认模型为 `deepseek-flash`，思考等级默认为 `low`。思考等级可在设置页自由填写；清空并保存后，请求中不会发送 `reasoning_effort`，以兼容不支持该参数的接口。Base URL 可以带 `/v1`，插件会拼接 `/chat/completions`。支持 HTTPS，以及 `localhost` 或 `127.0.0.1` 上的 HTTP 服务。API Key 存在 Chrome 本机扩展存储中，不会插入到网页或分析面板。

“提示词设置”默认显示扩展内置的系统提示词。可以修改，也可以点击“恢复默认”将编辑框还原；两种操作都要点击“确定”才会保存。成功保存后设置窗口自动关闭。分析完成的结果保存在本机，重新进入同一提交页时会直接恢复；只保留最近 10 个提交的结果，点击“重新分析”可更新缓存。

## 提取规则

- 通过域名、URL 的 `/training/<数字>/submission/<数字>` 或 `/submissions/<数字>` 路径，以及页面的三个固定区域共同识别提交页；WebVPN 地址还须含 `/https/<代理标识>/` 或 `/http/<代理标识>/` 前缀。
- 从源码区读取原始复制内容，从编译区只保留真正的编译错误；测试点弹窗即使关闭也可读取。
- 点击分析时使用“返回题目”链接获取同源题面：训练提交页接受同一训练下的 `/part/<数字>/problem/<数字>`，通用提交页接受同一站点下的 `/problems/<数字>`；WebVPN 页面还须保持相同代理前缀。题面无法获取或正文缺失时提示重试，不发送分析请求。
- WA 保留已提供的 `Judge/Jury` 标准答案与 `Team/Him` 用户输出。RE、TLE、MLE 等保留错误详情及有关退出状态。缺失的样例字段直接省略。AC 不发起分析。
- 提示词总长限制为 24,000 字符，为题面预留篇幅，并保留失败证据和差异附近文本。删减处标记 `[内容过长，已截断]`。

题面、源码和评测信息只有在用户点击分析按钮后，才发送给已配置的接口服务。模型回复会流式显示并渲染 Markdown；原始 HTML、图片和不安全链接不会执行或加载。内置系统提示词位于 `extension/prompts/system.md`。若接口明确不支持流式请求，插件会自动重试一次非流式请求。

## 验证

在仓库根目录运行 `npm ci && npm test`。测试覆盖两类提交页识别、WA/CE/RE/TLE/MLE/AC 的筛选、截断预算、思考等级设置，以及后台请求和错误处理。直连页需要在校园网内做实际验收；已用保存的 WebVPN 通用提交页核对 DOM 与题目链接。
